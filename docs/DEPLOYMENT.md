# CivicFix: Deployment

The live site is **https://civicfix-jnhd.onrender.com**.

| Part | Service | Plan | Region |
|---|---|---|---|
| Web server (API + built React app) | [Render](https://render.com) web service | Free | Singapore |
| Database | [Neon](https://neon.com) PostgreSQL | Free | AWS Asia Pacific (Singapore) |
| Photos | Stored inside PostgreSQL (`photos` table) | | |

Render's free disk is wiped on every restart, so photos can't be kept as files there. With `STORAGE_DRIVER=database` each photo is saved as a WebP image in the database. A typical photo is 50–300 KB, so the free database storage holds thousands of them.

## How a deploy works

[`render.yaml`](../render.yaml) is a Render **Blueprint**. On every push to `main`, Render:

1. **Builds:** `npm ci --include=dev && npm run build` (Vite is a dev dependency, so dev dependencies are installed).
2. **Starts:** `npm run db:migrate && npm run db:seed && npm start`. Migrations and the seed only add what is missing, so they are safe to run on every start.
3. **Checks health** at `/api/health` before sending traffic to the new version.

## Environment variables

| Variable | Value on Render | Notes |
|---|---|---|
| `NODE_ENV` | `production` | |
| `NODE_VERSION` | `22` | |
| `TRUST_PROXY` | `1` | Render puts one proxy in front of the app; needed for correct client IPs in rate limiting |
| `JWT_SECRET` | generated by Render | Long random value; never committed |
| `DATABASE_URL` | Neon connection string | Secret (`sync: false`) |
| `DATABASE_SSL` | `true` | |
| `STORAGE_DRIVER` | `database` | Photos in PostgreSQL |
| `SEED_ADMIN_EMAIL`, `SEED_ADMIN_PASSWORD` | your admin login | Secret. The seed refuses the demo password in production |
| `SEED_DEMO` | `true` | Loads the demo citizen and 10 sample reports for the college demo |

Secrets live only in Render's settings and in local `server/.env` files, which Git ignores. They are never committed.

## Setting it up from scratch

1. **Neon:** create a project (region: Singapore) and copy its connection string. It starts with `postgresql://` and ends with `?sslmode=require`.
2. **Render:** sign in with GitHub, choose **New + → Blueprint**, and select this repository.
3. Enter `DATABASE_URL`, `SEED_ADMIN_EMAIL` and `SEED_ADMIN_PASSWORD` when Render asks for them, then click **Apply**. The first build takes about 5 minutes.
4. When the service shows **Live**, open the site. Log in at `/admin/login` with the admin account, and as `citizen@civicfix.demo` / `Citizen@12345` for the citizen side.

## Things to know

- **Cold starts:** the free service sleeps after 15 minutes without visitors, and the first request after that takes about a minute. Open the site a couple of minutes before a demo.
- **Shared free hours:** Render gives each account 750 free hours a month across all free services.
- **Database connection drops:** Neon closes idle connections. The server's connection pool handles this and reconnects instead of crashing.
- **No delete button:** to hide a test report, log in as admin and reject it with a reason.
